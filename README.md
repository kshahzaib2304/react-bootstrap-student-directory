# React Bootstrap Student Directory

A responsive Student Directory application built with React.js and Bootstrap 5, featuring interactive student management, reusable components, profile views, search functionality, and pagination.

## Overview

This project demonstrates modern React frontend development using functional components, props, React Hooks, event handling, and Bootstrap's responsive grid system.

The application provides an interactive interface for managing and viewing student records.

## Features

- **Student Directory:** Display student records using responsive Bootstrap cards.
- **Add Students:** Add new student records through an interactive form.
- **Delete Students:** Remove student records dynamically.
- **View Profiles:** Track individual student profile views.
- **Show / Hide Details:** Toggle student information using React state.
- **Search:** Find students by name or student ID.
- **Pagination:** Navigate through student records.
- **Responsive UI:** Supports desktop, tablet, and mobile screens.
- **Interactive Alerts:** Display feedback for user actions.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/kshahzaib2304/react-bootstrap-student-directory.git
```

Navigate to the project:

```bash
cd react-bootstrap-student-directory
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.
